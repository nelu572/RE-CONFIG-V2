# Unity 검증

코드·씬·프리팹·에셋 변경 뒤 검증을 요청받거나, 커밋·PR 전에 적용한다. 변경 범위에 맞는 항목만 실행하며, 실행하지 않은 검증은 통과했다고 말하지 않는다.

## 공통

- Unity Editor Console에 이번 변경으로 생긴 컴파일 오류나 예외가 없는지 확인한다.
- 변경한 에셋을 다시 열어 누락된 참조와 컴포넌트 경고가 없는지 확인한다.
- Play Mode 검증 뒤 종료하고, 의도한 에셋 변경이 실제 파일에 남았는지 확인한다.

## 변경 범위별 확인

- 코드: 컴파일 성공과 변경한 기능의 핵심 흐름을 확인한다.
- 씬·프리팹: 씬 계층, 인스펙터 값, 카메라·콜라이더·정렬 상태를 확인한다.
- ROOM: 시작부터 핵심 퍼즐 흐름, 재시작 또는 ROOM 재진입 시 상태를 확인한다.
- UI·입력: 메뉴를 열고 닫는 흐름과, UI 입력이 게임플레이 입력과 충돌하지 않는지 확인한다.

## V2 퍼즐 기준

- 변경한 ROOM이나 규칙은 플레이어가 결과와 실패 원인을 관찰할 수 있는지 확인한다.
- 정확한 조작·순간 반응만으로 핵심 해법을 요구하는 회귀가 없는지 확인한다.

## 커밋·PR 전

- `git diff --check`를 실행한다.
- 새·이동·삭제된 `Assets` 원본과 대응 `.meta` 파일을 함께 확인한다.
- `Packages/` 또는 `ProjectSettings/` 변경은 의도와 영향을 검토한다.
